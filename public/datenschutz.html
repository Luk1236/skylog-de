Datenschutzerklärung

SkyLog DE – Drohnen Flugbuch
Stand: Juni 2025

1. Verantwortlicher

Diese App wird als Einzelprojekt betrieben. Anfragen richten Sie bitte per E-Mail an die in den App-Store-Metadaten hinterlegte Kontaktadresse.

2. Welche Daten werden verarbeitet?

SkyLog DE speichert alle Daten ausschließlich lokal auf Ihrem Gerät (IndexedDB im Browser / PWA-Storage). Es werden keine personenbezogenen Daten auf externe Server übertragen, gespeichert oder an Dritte weitergegeben.

Lokal gespeicherte Daten umfassen:

  • Pilotenprofil (Name, LBA e-ID, Lizenzinformationen)
  • Drohnen- und Akkuinformationen
  • Flugprotokolle (Ort, Datum, Dauer, Wetter, Notizen)
  • Hochgeladene Dokumente und Fotos

3. Externe Dienste

Die App ruft folgende externe Dienste ab – dabei werden keine personenbezogenen Daten übertragen, lediglich technische Parameter (GPS-Koordinaten für Wetterdaten):

  • Open-Meteo API (open-meteo.com) – Wetterdaten und Vorhersage anhand von GPS-Koordinaten. Datenschutz: open-meteo.com/en/terms
  • FAA NOTAM API (api.faa.gov) – NOTAM-Daten (optional, nur wenn API-Key hinterlegt). Datenschutz: faa.gov/privacy
  • QR Server API (api.qrserver.com) – QR-Code-Generierung für die LBA e-ID (nur die eingegebene e-ID wird übertragen). Datenschutz: goqr.me
  • OpenStreetMap / Leaflet – Kartenmaterial. Datenschutz: osmfoundation.org
  • DIPUL WMS (Luftfahrt-Informationsdienst Deutschland) – Luftraumdarstellung auf der Karte

4. GPS / Standortdaten

Die App fragt Standortdaten (GPS) ab, um die Karte zu zentrieren und Wetterdaten für Ihren Standort zu laden. Diese Daten werden nicht gespeichert oder übertragen, außer als Teil des Flugprotokolls, das lokal auf Ihrem Gerät verbleibt.

5. Ihre Rechte

Da alle Daten lokal auf Ihrem Gerät gespeichert werden, können Sie diese jederzeit selbst löschen – über die Browser-Einstellungen (Websitedaten löschen) oder die integrierte Backup/Restore-Funktion der App. Es gibt keine zentrale Datenbank, bei der Löschanfragen gestellt werden müssten.

6. Änderungen dieser Erklärung

Diese Datenschutzerklärung kann bei Funktionserweiterungen der App aktualisiert werden. Die jeweils aktuelle Version ist in der App verlinkt.
